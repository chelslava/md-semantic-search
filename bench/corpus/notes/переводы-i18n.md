# Переводы приложения

## Как добавить новый язык

1. Создайте файл перевода `locales/<lang>.json`.
2. Продублируйте структуру ключей из `locales/ru.json`.
3. Добавьте язык в список поддерживаемых в конфигурации.
4. Проверьте, что строки с плейсхолдерами (`{name}`) не разбиты.

## Статус переводов

Статус каждого языка отслеживается в таблице `locales/STATUS.md`:
полный, частичный или устаревший. Сборка падает, если ключ
отсутствует хотя бы в одном языке.

## Локализация дат

Даты и числа форматируются через Intl API по выбранной локали,
не склеивайте строки вручную.
