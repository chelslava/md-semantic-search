# Синхронизация заметок

## Как устроена синхронизация

Заметки хранятся в git-репозитории. Пуш и пулл происходят вручную,
автокоммиты отключены, чтобы не плодить мусорные истории.

## Конфликты

При одновременном редактировании одного файла git создаёт конфликт.
Разрешение конфликта — ручное: выберите нужный фрагмент, уберите
маркеры `<<<<<<<` / `=======` / `>>>>>>>`.

## Вложенные вики-ссылки

Ссылки вида `[[страница]]` обновляются Obsidian автоматически при
переименовании. После ручного переименования проверяйте входящие
ссылки поиском по имени.
