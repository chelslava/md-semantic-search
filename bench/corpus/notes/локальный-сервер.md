# Локальный сервер

## Привязка и безопасность

Демон поиска по умолчанию слушает `127.0.0.1`. Флаг `--host 0.0.0.0`
включается только когда сервер намеренно открывается в сеть, и тогда
перед ним должен стоять обратный прокси или файрвол.

## Эндпоинты

- `POST /search` с телом `{"query": "...", "k": 5}`.
- `GET /health` возвращает `{ok, chunks, model, dim, built}`.

## Ограничения запросов

Тело запроса ограничено 64 КБ. Битый JSON возвращает 400,
превышение размера — 413.
