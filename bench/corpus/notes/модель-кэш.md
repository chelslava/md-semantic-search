# Кэш моделей

## Где хранятся модели

Веса скачиваются в `~/.cache/mdss` (переопределяется через
`MDSS_CACHE_DIR`). Структура — FileCache из transformers.js:
каталог на каждую модель, внутри подкаталог ревизии для закреплённых id.

## Первый запуск

Первый запуск скачивает квантованные веса (примерно 280 МБ для
e5-base), после этого поиск работает полностью офлайн. Удаление
каталога кэша форсирует чистую перекачку повреждённой модели.

## Проверка кэша

`mdss check` проверяет структуру кэша без загрузки модели:
отсутствие кэша — предупреждение, а в режиме `--offline` — ошибка.
